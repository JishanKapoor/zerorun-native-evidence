# Ordinary semantic checks

These source-distribution helpers provide separately implemented conventional
checks. They import neither the production ZeroRun interpreter nor PyContract.
They are author/AI-authored code, not an independent investigator or a measured
N/G study arm. Reusing an adequate helper costs no new construction; the release
does not claim that users must reconstruct it for each case.

`relationships.run(profile, case, events, health)` accepts the disclosed,
already-admitted primitive rule/event schema and returns
`(relationship_id, group_identity, status)` rows in rule/group order. Schema and
source-site qualification remain explicit prerequisites. This function does not
invoke a native evaluator, execute source bindings or certify arbitrary raw
callbacks. Its input contains primitive observations and acquisition premises;
it never receives production relationship verdicts or expected grades.

The semantic fragment covers C1 required commitments, C2 identity and
boolean/integer conversions, C3 conjunction/status membership and declared
target mappings. It handles finite native guards, absence under complete native
and transport premises, ambiguous identities, source-site coverage, and
required-role health. Rules with producer roles or guards close coverage over
all relevant source/consumer/guard kind aliases. Unrelated producer loss cannot
erase a supported local relation; witnessed contradictions are retained when
missing premises prevent successful conformance.

For `complete_batch_membership`, the ordinary implementation reads the raw
begin/element/end journal itself. It checks acquisition ordering, group and
producer identity, end matching and admitted event equality. Only a unique
closed native population can supply the additional membership premise. Empty
populations are explicit; lost ends preserve positive evidence without proving
closure. Acquisition positions and stored scientific identities remain separate.
A complete independently frozen scientific inventory can still establish its
own relationship when this additional batch premise is unavailable. The
implementation imports no production batch reconciler or completeness flag.

`checks.py` and `qualification.py` retain the older fixed-family application
interface and source/observation agreement checks. They are not aliases for the
new declarative grammar. Native recipe directories additionally contain
source-specific raw assertions (for example native writer-to-reader populations
and Inspect metric inputs); their reported arithmetic/native properties are
distinct from the finite generic C1–C3 status interpreter.

The tests include explicit distinguishing controls and separate semantic parity
checks. The study evidence also records replay over retained native acquisitions
without new native calls. Agreement is a cross-check within this bounded
contract, not proof of oracle correctness, universal transfer, independently
measured benefit or external peer review. Ordinary helpers and their complete
dependencies remain eligible adequate alternatives in any later study.
