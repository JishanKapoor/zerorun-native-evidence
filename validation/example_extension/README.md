# Exposed native declaration package

This separately installable example registers three finite declarative profiles through `zerorun.extensions.v1`: an authored C1–C3 control and pinned EvalPlus/SWE native API aggregate controls. It contains declarations only. The ZeroRun framework owns matching, binding, qualification and relationship interpretation.

This package was authored as framework development material. It is not the independently authored Inspect extension or independent scientific-use evidence required by R11.
