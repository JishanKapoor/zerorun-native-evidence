# Original native SWE chain in one invocation

This development adapter observes the original parser, selected map, F2P/P2P
decisions and list commits, construction of the grading report, native resolution,
report-map fields, actual run_instance JSON writer, closed report-file consumer,
category commits, aggregate construction and aggregate JSON writer in the same
execution. It calls original normal-imported upstream code. It uses the saved-log
rewrite path, not Docker patch/test execution.

Each capture is restricted before execution to exactly the declared native
instance `a`. The internal instance identity comes from that frozen input context;
the writer and reader instance identities come from native locals. Input-derived
inventories contain both native resolution operands and every test obligation.
Native internal and reporting phases remain separate, with explicitly declared
bridge identities. No post-hoc event relabeling or cross-execution join occurs.

The before/after profiles have 57/59 logical sites, 60/62 static source matches,
30/32 fact kinds and 30 relationships. The 23 reporting views are a scoped subset
of the separately qualified S8 reporting campaign. The eight list construction
views preserve actual F2P/P2P success/failure lists in their original dictionary
fields. All source fixtures preserve the already exposed upstream bytes.

`reference.py`, `internal_reference.py` and `ordinary.py` use unchanged native
execution, standard-library tracing and independent raw-field/file assertions;
none imports the production policy, mapper or verdict checker. Authored controls
are development qualification, not new historical cases, independent users or
external peer review. `prepare.py` must freeze code, controls, source, inventory
and image identity before `campaign.py` executes native calls.
